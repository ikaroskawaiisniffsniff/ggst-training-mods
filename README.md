# GGST 训练场模组

适用 Steam 版 Guilty Gear -Strive-，build 24797162。三个模组都是独立的，可以只装其中一个，也可以一起装。

| 模组 | 单独能做什么 | 一起装时 |
| --- | --- | --- |
| 状态存档 | 自己画右上角的 8 栏存档 | 跟另外两个共用一次 F6 |
| 格挡反击 | 自己画中间的延迟窗口，格挡从第几下出手，停手 120 帧后重计 | 同一次 F6 打开三个窗口 |
| F式防御 | 自己画左下角的开关状态，F7 开关，F8 重置首防 | 状态窗由格挡反击那一次绘图带出来 |

不要和 SF6TrainingMenu 一起开。

## 两种装法

每个模组文件夹里都有两套同样的文件：

- `直接安装`：把里面的 `Mods` 文件夹复制到游戏的 `RED\Binaries\Win64\Mods\`，再在 `mods.txt` 里把对应那一行设成 1。
- `模组管理器`：用 Unverum。把该模组的管理器文件夹放进 `Mods\Guilty Gear -Strive-`，勾上后 Build。格挡反击和旧的反击延迟会写进同一个 `SF6ReversalDelay` 文件夹，只能留一份。

各文件夹里的说明书写了按键。一起装时：

- F6：三个窗口一起打开、一起关掉。延迟在中间，存档在右上角，F 式防御在左下角。
- 存档：Q/E 选栏，O 保存，P 读取。
- 格挡反击：W/S 换条件，A/D 调帧，选中格挡反攻时 J/K 调第几下，U 开关。
- F式防御：F7 开关，F8 让下一击重新站防。
