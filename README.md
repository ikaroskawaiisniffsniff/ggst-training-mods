# GGST 模组管理器版

这三个包来自模组管理器目录，是当前使用的版本。适用 Steam 版 Guilty Gear -Strive-，build 24797162。用 Unverum 安装。

三个模组都可以单独使用，不依赖另外两个。只勾选要玩的那一个，然后 Build。

- GGST-状态存档：只存 8 个栏位的位置和状态。F6 打开右上角列表。
- GGST-格挡反击：只做格挡第几下反击和延迟。F6 打开中间的窗口。
- GGST-F式防御：只做 F 式防御。单独装时自己画左下角状态窗。F7 开关，F8 重置。

不要和 SF6TrainingMenu 一起开。

每个文件夹里的说明书写了安装步骤和按键。同名 zip 是同一份包，可以直接丢给 Unverum。
